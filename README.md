🏆 Shared Treasure Box

A collaborative savings application that helps families and friends save toward shared goals like travel, dining, or pets, with a social, interactive twist on tracking money.

✨ Overview

Shared Treasure Box turns group saving into a fun and transparent experience. Users can create shared “Treasure Boxes” for specific goals, contribute funds, track expenses, and interact through a social transaction ledger.

🚀 Features
📦 Global Dashboard (Home)
View all shared savings boxes in one place
Large, visually rich cards with:
Box name
Current balance
Member avatars
Floating Action Button (+):
Create a new Treasure Box
Tap a box to view details

💰 Treasure Box Detail (Hub)
Central view for each savings goal
Displays:
Cover image
Total balance
Key actions:
Deposit (add money)
Withdraw (log expenses)

🧾 Social Ledger
Full transaction history
Each transaction includes:
Name + amount
Comment button
Inline comments:
Expandable thread under each transaction
Reactions + messages from collaborators
No page navigation required

➕ Create New Treasure Box
Accessible via the "+" button on Dashboard
Form inputs:
Box Name (e.g., Japan Trip 2026)
Target Amount
Collaborators (search by username/ID)
Cover Image Upload
Saves and returns to Dashboard

📥 Deposit Flow
Add money into a Treasure Box
Inputs:
Transaction Name (e.g., Monthly Contribution)
Amount (numeric keypad)
Confirm with Deposit button

📤 Withdraw Flow
Record spending from the box
Inputs:
Expense Name (e.g., Dinner at Joe’s)
Amount
Optional note
Confirm with Log Expense

🧠 Concept

This app blends:

💸 Financial tracking
👨‍👩‍👧‍👦 Social collaboration
📱 Clean mobile-first UI

Unlike traditional budgeting apps, Shared Treasure Box emphasizes shared accountability and communication through its social ledger system.
